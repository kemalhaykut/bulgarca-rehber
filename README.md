# Bulgarca Rehber

Türkçe anlatımlı A1–A2 Bulgarca dilbilgisi uygulaması (Android).

- 14 ders (A1: 1–7, A2: 8–14) — konu sırası "Здравейте!" (НБУ) ders kitabını izler
- Her derste: Gramer ve Örnekler · Okuma Metni · Alıştırma
- Bulgarca kelimeye dokun / basılı tut → Türkçe anlam, okunuş, vurgu, dilbilgisi
- 6 tema, yazı boyutu, ilerleme kaydı

İçerik kaynağı: `tools/` (Python) → `site/data.js`. Uygulama: `site/app.html`.
Android paketi: `tools/make_web.py` ile `assets/web/` hazırlanır; GitHub Actions APK'yı derler.
